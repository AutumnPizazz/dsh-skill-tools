# 0.1.0 发布前验证

环境：Node 26.13.0；dsh/Cordis 0.2.2-rc.1 / 4.1.0。运行时没有第三方依赖。

- 39 项单元/真实框架测试全部通过，含四个官方预设对应的 scope 结构、自定义预设、已有/新 agent、服务晚启动、卸载回滚、原生 provider 策略、URL/opaque 资源基址。
- 46 条本机真实技能查询命中正确；原算法固定语料 52 查询×4 配置=208 组，结果、分数、覆盖率、命中完全一致。
- 额外 1 项真实 PTC 集成通过：官方 Node runtime + 官方本地只读 sandbox；外层仍只有 run_code，SDK 暴露两技能工具，实际嵌套搜索/加载成功，既有 guard 拒绝仍生效。
- npm prepack 自动测试通过，明确白名单只打包 9 个文件；无测试、技能正文、本机路径、凭据、日志、工作计划或开发依赖。
- tarball 安装到独立 profile，仅安装 1 个包；可解析插件入口，安装后的 CLI 实际检索成功。
- 未改 dsh 源码、运行中的旧插件或用户配置；未调用模型、付费服务或远程系统。

PTC 测试首次挂起源于隔离 session 夹具缺少 append 合同，补齐后通过；没有修改 dsh 或降低 sandbox。Node 的 stripTypeScriptTypes ExperimentalWarning 为官方 runtime 所产生，不影响验证。

仓库的普通 npm test 不启动完整 dsh 应用；它使用真实服务和预设对应作用域结构。PTC 进程级测试单独运行。完整交互式 dsh 切换与生产热加载尚未执行。
